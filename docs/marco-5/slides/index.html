#31 / COMUNICAÇÃO COM A API

Enviar a exclusão para a API

src/lib/api.ts
// url: /tarefas/ID
const resposta = await fetch(url, {
  method: 'DELETE'
});
if (!resposta.ok) {
  throw new Error(...);
}

RESPOSTA HTTP

204

No Content: sucesso,
sem corpo de resposta.

resposta.ok verifica o sucesso. Em 204 não há corpo para converter com resposta.json().

O fetch envia o pedido; o json-server remove o registro do db.json. Nenhuma biblioteca nova foi instalada.

#32 / ESTADO REATIVO NO SVELTE 5

Encerrar o carregamento no Svelte

await espera a resposta de listarTarefas. O resultado é guardado em tarefas.

finally roda no sucesso e na falha: carregando volta para false e encerra o aviso de espera.

$state torna o valor reativo: ao mudar, o Svelte atualiza o trecho da tela que lê esse valor.

Trecho do carregamento
try {
  tarefas = await listarTarefas();
} /* catch trata a falha */
finally {
  carregando = false;
}

No template, {#if carregando} mostra a espera enquanto o valor é true. Quando vira false, o Svelte avalia o próximo bloco.

#36 / FALHA AO SALVAR

Preservar os campos quando salvar falha

Simulação local: nenhum dado é enviado à API.

Os campos usam bind:value. O catch muda só erroEnvio. Como campos não é zerado, o texto permanece.

TarefaFormulario.svelte
try {
  await aoEnviar({ ...campos });
} catch {
  erroEnvio = 'Não foi possível...';
} finally {
  enviando = false;
}

aoEnviar é recebido por prop: no cadastro chama criarTarefa; na edição, atualizarTarefa. finally libera o botão para outra tentativa.

#36 / FALHA AO EXCLUIR

Tratar o erro sem remover a tarefa

Preparar a apresentação

A tarefa permanece nesta simulação.

Simulação local: a API real não é acessada.

Se DELETE falhar, o catch mostra o erro. O finally muda excluindo para false e libera o botão.

TarefaCard.svelte
try {
  await excluirTarefa(tarefa.id);
  onexcluir(tarefa.id);
} catch {
  erroExclusao = 'Não foi possível...';
} finally {
  excluindo = false;
}

onexcluir só executa depois do await bem-sucedido. Em falha, a página não recebe ordem para remover o cartão.
