#32 / ESTADO REATIVO NO SVELTE 5

Como a reatividade atualiza a tela.

await aguarda os dados sem bloquear a página inteira.

finally encerra a espera, mesmo quando a busca falha.

$state permite ao Svelte acompanhar os valores usados na interface.

Trecho do carregamento
try {
  tarefas = await listarTarefas();
} /* catch trata a falha */
finally {
  carregando = false;
}

Não escondemos o HTML manualmente. O bloco {#if carregando} reage ao novo valor.

#36 / FALHA AO SALVAR

O erro não apaga o formulário.

Simulação local: nenhum dado é enviado à API.

Os campos usam bind:value. O catch altera o aviso, sem limpar o estado do formulário.

TarefaFormulario.svelte
try {
  await aoEnviar({ ...campos });
} catch {
  erroEnvio = 'Não foi possível...';
} finally {
  enviando = false;
}

Cadastro e edição reutilizam o formulário. Em falha, a pessoa continua na página com o texto preservado.
