#31 · EXCLUSÃO COM CONFIRMAÇÃO

Excluir uma tarefa com segurança

A pessoa confirma a ação. A lista só muda depois que a API confirma a exclusão.

Clicar em ExcluirConfirmarDELETE na APIAtualizar a lista

Cancelar

Não envia a requisição e mantém a tarefa.

Confirmar

Aguarda a API antes de retirar o cartão.

Gabriel Crispim Galvão · Svelte 5 + SvelteKit · demais issues do marco serão acrescentadas após a implementação.

COMUNICAÇÃO COM OS DADOS

Como a exclusão chega à API

Função em api.ts

excluirTarefa(id)

DELETE /tarefas/ID

O json-server remove o registro do db.json.

O que foi necessário

Codificar o ID, conferir o status HTTP e aceitar uma resposta sem corpo.

204 No Content

Não tentamos converter essa resposta em JSON.

Nenhuma biblioteca nova. A confirmação usa window.confirm, do navegador.

INTEGRAÇÃO COM O SVELTE

Como o cartão avisa a página

No cartão

await excluirTarefa(tarefa.id);
onexcluir(tarefa.id);

O callback só é chamado depois do sucesso da API.

Na página da lista

tarefas = tarefas.filter(
  tarefa => tarefa.id !== id
);

$state guarda a coleção. $derived reaplica os filtros.

O Svelte atualiza os cartões que dependem desses dados, sem F5.
