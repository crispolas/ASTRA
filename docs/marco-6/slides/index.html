#39 · Configuração

src/lib/configuracao.ts

import { PUBLIC_API_URL }
  from '$app/env/public';

export const API_URL =
  PUBLIC_API_URL.replace(/\/+$/, '');

#39 · Build e variável de ambiente

O SvelteKit incorpora a URL no build

Edite o valor e gere outra versão.

URL incorporada ao JavaScripthttps://astra-api-4upe.onrender.com

Em src/env.ts, a declaração usa public: true e static: true.

O valor precisa começar com HTTP ou HTTPS. Se estiver ausente ou inválido, a configuração é rejeitada.

Mudar a variável exige gerar e publicar outro build.

#42 · Saída estática

O adapter prepara o destino da aplicação

vite.config.ts · trecho simplificado

import adapter from
  '@sveltejs/adapter-static';

sveltekit({
  adapter: adapter({
    fallback: 'index.html'
  })
});

Foi instalado @sveltejs/adapter-static, substituindo o adapter anterior.

Na publicação registrada, a aplicação roda no navegador, com ssr = false.

A Netlify serve HTML, CSS e JavaScript. A API continua no Render.

Configuração da publicação documentada no Marco 6.
